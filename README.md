## 1. README

### What it is
A self-testing GCSE Maths practice tool for Intermediate Tier students (Grades 4–6). 149 randomised question factories across Number, Algebra, Geometry & Measure, Circle Theorems, and Statistics & Probability — every question regenerated with fresh numbers each time, so there's no risk of memorising answers instead of the method. Compatible with AQA, Edexcel, WJEC and IGCSE.

### Who it's for
- Students working towards GCSE Intermediate Tier Maths, targeting Grades 4–6
- Students bridging the gap between Foundation and Higher tier work
- Tutors and teachers wanting a self-marking practice bank to set for independent revision
- Home-schoolers and self-studiers wanting unlimited, varied practice rather than a fixed set of questions

### What's inside
**149 question factories**, broken down as:
- Number — 44 factories
- Algebra — 34 factories
- Geometry & Measure — 40 factories
- Circle Theorems — 7 factories
- Statistics & Probability — 24 factories

Every question is randomised on generation — the same factory produces a different version each time — so genuine repeated practice is possible without ever seeing the same numbers twice.

- **Unlimited randomised multiple-choice questions** — a new question every time
- **Full worked solutions** with step-by-step methods, revealed on demand
- **Mock Paper Mode** — generates an instant 10-question practice paper
- **Print Paper mode** — for offline, pencil-and-paper revision
- **Live scoring** (Correct / Wrong / Score) as you go

### How to use it
Open the page in any browser — nothing to install. Tap New Question to generate a fresh question from any factory, or switch to Mock Paper Mode for a ready-made 10-question paper. Use Print Paper mode whenever you want an offline version.

No app, subscription or account required. Fully private — nothing stored or tracked. Works in any browser on any device.

**Live app:** https://goyaklaarchimedes.github.io/Mr-Nathan-GCSE-Maths-Question-Bank-Intermediate-Tier/

### A note on exam boards
Compatible with AQA, Edexcel, WJEC and IGCSE — these describe the general style and level of a question, not certification against one current, dated specification. Always check your own board's up-to-date specification for definitive guidance.
